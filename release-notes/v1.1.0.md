第一个正式签名的版本，也是重写之后的第一次发布：记账的计算和判断都在 Rust 核心里，界面用 Flutter 画，只做 Android。

## 安装

下载下面的 `app-arm64-v8a-release.apk`，在手机上打开安装。近几年的 Android 手机都是 arm64。

这一版是正式签名的，以后的版本可以直接覆盖安装，账本不受影响。

## 从测试版换过来

之前的测试版是调试签名的：打开 设置 › 关于大红花，版本号后面带 `-debugsigned` 的就是。Android 不允许正式签名的版本覆盖它，必须先卸载，而卸载会把账本一起删掉。所以先把账本带出来：

1. 在旧版里打开 我的 › 备份，点右上角的 ＋ 备份一份。**不要给这份设口令**：设了口令的快照不带小票照片，照片会随卸载一起删掉。
2. 在这份快照上点「导出」，存到手机的文件里，或者发给自己。
3. 卸载旧版，安装这一版。
4. 打开 我的 › 备份 › 从文件恢复，选刚才导出的文件。有小票照片的话，把导出的照片一起选上。

v1.0.0（React Native 版）的账本带不过来：这一版读不了它导出的文件。

## 这一版有什么

- **记一笔**：每记一笔贴一朵花。可以选日期和时间、子分类、外币（输入时显示折合多少）、转账手续费和优惠，也可以在这里直接新建分类。编辑时可以删除，或者照这笔再记一笔。
- **明细**：顶部是这个周期的汇总、预算和一句提示，可以往前翻看以前的周期；可以切到日历；可以按账本筛选；搜索可以按收支、日期和分类筛。信用卡快到还款日时会提醒。
- **预算**：每个周期和每天的上限，也可以给分类单独设；会估算月末花多少。记一笔后快超或超了会提醒一句。
- **统计、回顾、下月预测**：回顾可以分享出去；下月预测照前三个周期的走势估下个周期。
- **自动记账**：授权后读取支付通知自动记下来。小米手机有保活的设置指引。
- **订阅**（也可以是定期转账）、**报销**、**退款**、**借贷**、**资产和净资产**、**多币种**（汇率可以联网更新）。
- **备份**：手动或自动（每天、每周），可以设口令，可以导出，也可以从文件恢复。两台手机之间同步是一个你自己带着走的文件。
- **AI**（默认关闭）：一句话记账、问账本、读小票。用的是你自己的钥匙，存在手机的加密存储里，不进任何备份和导出。
- 删除前都会先问；可以隐藏金额；有应用锁和桌面小组件；中文和英文；省电模式下不做毛玻璃模糊。

除了查汇率和你打开 AI 之后按下的那一下，这个应用不联网。

## English

The first properly signed release, and the first of the rewrite: a Rust core that does the arithmetic and the judgement, and a Flutter UI. Android only.

**Install** the `app-arm64-v8a-release.apk` below. Later versions will install over this one and keep the ledger.

**Coming from a test build?** Those were debug-signed (设置 › 关于大红花 shows `-debugsigned`), and Android will not let a signed build replace one, so the old one has to be uninstalled, and the uninstall takes the ledger with it. Carry it across first: in 我的 › 备份, take a snapshot with ＋ **without a password** (a sealed snapshot leaves its receipt photos behind), 导出 it, uninstall, install this, then 备份 › 从文件恢复 and pick the file, with its photos if it has any.

The ledger from v1.0.0, the React Native app, cannot be carried over: this version cannot read its export.
